## 开源小工具

### [travel-pgc-cleaner](./tools/travel-pgc-cleaner)

旅游 PGC 批处理工具：支持正文清洗、段落去重、营销尾注过滤、图片链接规范化，以及 CSV / XLSX 批量输入输出。

### [scenic-geo-auditor](./tools/scenic-geo-auditor)

景区坐标核验工具：组合名称相似度、行政区一致性、原坐标距离和 POI 类型，输出自动通过、人工复核、无匹配或未找到。

### [coze-travel-image-workflow](./tools/coze-travel-image-workflow)

脱敏后的文旅文生图工作流：包含工作流结构、八路提示词生成器和密钥检测校验器。

这些工具与产品来自文旅元服务运营和个人产品实践中的真实问题。公开版本使用模拟或脱敏数据，不包含客户原始资料、账号、访问凭据或服务端密钥。
