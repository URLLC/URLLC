### 塘栖古镇文旅元服务运营

**项目范围**

参与方案、内容建设、商户协同、上线测试、线下活动和项目复盘全流程。

**团队成果**

- 完成 21 家商户入驻，其中 8 家配置体验权益
- 完成 13 个 Beacon 点位和 210 张免费体验券配置
- 媒体矩阵相关内容浏览量合计 19,077

**个人职责**

- 负责核心景点、出入口、停车场、卫生间等基础数据
- 推进 PGC 上传、游览路线调整、商户优先级和线下物料落地

- 沉淀六阶段线下活动执行 SOP

### PGC 游记内容批处理

- 借助 Codex 将微信文章采集、正文清洗、图片筛选去重、二维码与低质图识别、断点续跑和 Excel 回写串成批处理流程
- 完成覆盖 **77 个元服务、228 条内容链接** 的输入批次处理
- 通过缓存、日志、失败快照和人工复核机制保证流程可追踪

### 扣子文生图工作流

- 在扣子（Coze）搭建景点内容文生图工作流
- 串联网搜、DeepSeek 景色特征提炼、标题处理、提示词生成与优化及并行出图
- 单次输出 **8 张景点推荐卡片素材**，用于文旅元服务内容生产

### 景区经纬度批量核验

- 设计并跑通基于高德 API 的景区坐标核验流程
- 结合行政区一致性、候选评分、距离判断、缓存重试和人工复核
- 实现 GCJ-02 坐标标准化、异常分流和结果追溯
