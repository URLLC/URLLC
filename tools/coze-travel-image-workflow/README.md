# coze-travel-image-workflow

一个脱敏后的文旅内容文生图工作流参考实现。仓库把“景点输入 → 联网资料 → 景色特征提炼 → 标题生成 → 提示词优化 → 八路并行出图”拆成可理解、可验证的节点，并提供一个无需模型即可运行的提示词包生成器。

这不是公司原始扣子导出包，不包含内部提示词、插件 ID、访问凭据或真实景区资料。

## 工作流

```text
景点输入
  └─ 联网资料检索
      └─ 景色特征提炼
          ├─ 主副标题生成
          └─ 出图提示词组装与优化
              ├─ 自然风光
              ├─ 人文纪实
              ├─ 晨景
              ├─ 夜景
              ├─ 航拍
              ├─ 近景细节
              ├─ 节气氛围
              └─ 旅行卡片
```

完整的脱敏节点与连线见 `workflow/workflow.json`。

## 生成八组提示词

```bash
python tools/build_prompt_pack.py ^
  --input examples/sample_input.json ^
  --output output/prompt_pack.json
```

输出包含：

- 主标题和副标题
- 八种视觉方向
- 每种方向对应的完整出图提示词
- 无水印、无二维码、无乱码等质量约束

## 校验工作流

```bash
python tools/validate_workflow.py workflow/workflow.json
python -m unittest discover -s tests -v
```

校验器会检查：

- 节点 ID 是否重复
- 连线是否引用不存在的节点
- 是否恰好包含八个图像生成节点
- 是否出现疑似 API Key 或 Token

## 如何映射到扣子

1. 用开始节点接收景点名称、城市、季节等输入。
2. 使用联网搜索插件获取公开资料。
3. 使用大模型节点提炼不超过三条景色特征。
4. 使用大模型节点生成适合移动端卡片的主副标题。
5. 用代码节点或文本处理节点组装八种提示词。
6. 接入提示词优化插件和图像生成节点。
7. 在结束节点汇总标题及八张图片。

模型与插件可以替换，仓库关注的是工作流编排方式，而不是绑定某个供应商。

## 安全边界

- 不提交真实扣子导出包中的插件 ID、账号信息或内部提示词。
- 示例景区与特征均为虚构数据。
- 上线前需要补充内容安全、版权和人工审核环节。
