# Dazi：留学生场景化轻社交 MVP

> 一个可在线体验的独立全栈产品案例，而不是仅展示界面的静态原型。

- 产品案例：[dazi.lol/case-study](https://dazi.lol/case-study)
- 线上体验：[dazi.lol](https://dazi.lol)

## 产品问题

刚到海外城市的留学生常有即时、具体的陪伴需求，但直接陌生匹配缺少共同话题与信任边界。Dazi 以具体活动作为关系起点，形成：

`发现活动 → 报名参与 → 共同活动 → 申请联系`

## 已实现能力

- 邮箱认证与会话管理
- 活动发布、筛选、报名、退出与评论
- 城市、标签与地图活动发现
- 个人资料与共同活动后的联系申请
- 生产环境部署与发布检查

## 技术与关键约束

| 范围 | 实现 | 解决的问题 |
| --- | --- | --- |
| 应用层 | Next.js 15、React 19、TypeScript、Tailwind CSS | 快速迭代产品体验与页面状态 |
| 身份 | Supabase Auth | 邮箱认证与用户会话 |
| 数据 | Supabase Postgres | 活动、报名、评论、联系申请等关系数据 |
| 一致性 | 触发器、检查约束、索引 | 参与人数同步、名额约束、重复申请拦截 |
| 权限 | Row Level Security（RLS） | 用户资料、报名和联系关系的最小权限访问 |
| 地图与发布 | Leaflet、Vercel | 地图展示和生产环境交付 |
